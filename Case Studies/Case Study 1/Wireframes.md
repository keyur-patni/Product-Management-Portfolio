# Wireframes 📱

Wireframes illustrate how the Patient Flow Management System supports each step of the clinic workflow. They focus on layout, hierarchy, and user flow rather than final design. Each wireframe aligns directly with the MVP features defined in the roadmap.

1. Digital Check‑In Screen
   This screen allows patients to check in quickly using a mobile device, kiosk, or QR code.

**Key elements**

- Check‑in button (primary CTA)

- Identity verification fields (name + DOB or phone number)

- Appointment confirmation details

- Status indicator (“Checked In”)

- Error messaging for unmatched identity

2. Patient Status Timeline
   This screen shows patients where they are in the visit and what comes next.

**Key elements**

- Horizontal or vertical timeline of visit stages

- Current stage highlighted

- Timestamps for each completed step

- Estimated wait time for next step

- Delay notifications

3. Nurse Triage Dashboard
   This dashboard helps nurses manage triage efficiently and prioritize patients.

**Key elements**

- List of patients “Ready for Triage”

- Urgency indicators

- Vitals entry modal

- Room availability alerts

- Status update buttons (“In Progress,” “Complete”)

4. Provider Ready‑to‑See Dashboard
   This dashboard gives providers a clear view of patients who are ready for consultation.

**Key elements**

- Patient cards with intake summary, vitals, reason for visit

- Visit status controls (“In Progress,” “Complete”)

- Alerts for urgent cases

- Real‑time updates across roles

5. Lab Order & Results Screen
   This screen supports lab technicians and providers by showing lab order status.

**Key elements**

- Pending lab orders list

- Test type, provider, and patient details

- Status controls (“In Progress,” “Complete”)

- Result notification banner

- Integration with follow‑up workflow

6. Billing Summary & Checkout
   This screen helps patients understand charges and complete checkout smoothly.

**Key elements**

- Itemized billing summary

- Insurance coverage breakdown

- Payment options (digital or in‑clinic)

- Post‑visit instructions

- Follow‑up scheduling CTA

7. Operational Analytics Dashboard
   This dashboard gives clinic managers visibility into performance and bottlenecks.

**Key elements**

- Average wait times by stage

- Throughput metrics

- Room utilization charts

- Peak‑hour analysis

- Export options
